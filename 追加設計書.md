## 追加機能の概要

### 1. FastAPI REST API

FastAPI側では、AI機能と軽量なデータ取得APIを担当する。

主なAPI：

```text
GET  /health
GET  /students
POST /ai/lesson-feedback
POST /ai/homework-suggestion
POST /ai/study-plan
```

### 2. PostgreSQL接続

FastAPIからPostgreSQLへ接続する。

用途：

```text
生徒情報の参照
AI生成履歴の保存
授業コメント生成ログの保存
```

### 3. OpenAI API連携

OpenAI APIを使って以下を生成する。

```text
授業記録から保護者向けコメントを生成
生徒の苦手分野から宿題案を生成
成績推移から学習計画を生成
```

### app/schemas.py

```python
from pydantic import BaseModel
from typing import List

class LessonFeedbackRequest(BaseModel):
    student_name: str
    subject: str
    lesson_content: str
    understanding_level: int
    teacher_note: str

class LessonFeedbackResponse(BaseModel):
    feedback: str

class HomeworkSuggestionRequest(BaseModel):
    student_name: str
    grade: str
    subject: str
    weak_points: List[str]
    available_minutes: int

class HomeworkSuggestionResponse(BaseModel):
    homework: List[str]
```

### app/services/openai_service.py

```python
from openai import OpenAI
import os

client = OpenAI(api_key=os.getenv("OPENAI_API_KEY"))

def generate_lesson_feedback(data) -> str:
    prompt = f"""
あなたは学習塾の講師です。
以下の授業記録をもとに、保護者向けの丁寧なコメントを作成してください。

生徒名: {data.student_name}
科目: {data.subject}
授業内容: {data.lesson_content}
理解度: {data.understanding_level}/5
講師メモ: {data.teacher_note}
"""

    response = client.responses.create(
        model=os.getenv("OPENAI_MODEL", "gpt-4.1-mini"),
        input=prompt
    )

    return response.output_text
```

### app/routers/ai.py

```python
from fastapi import APIRouter
from app.schemas import LessonFeedbackRequest, LessonFeedbackResponse
from app.services.openai_service import generate_lesson_feedback

router = APIRouter()

@router.post("/lesson-feedback", response_model=LessonFeedbackResponse)
def lesson_feedback(request: LessonFeedbackRequest):
    feedback = generate_lesson_feedback(request)
    return {"feedback": feedback}
```

## PostgreSQL接続設計

### app/database.py

```python
import os
from sqlalchemy import create_engine
from sqlalchemy.orm import sessionmaker, declarative_base

DATABASE_URL = os.getenv("DATABASE_URL")

engine = create_engine(DATABASE_URL)
SessionLocal = sessionmaker(
    autocommit=False,
    autoflush=False,
    bind=engine
)

Base = declarative_base()
```

### app/models.py

```python
from sqlalchemy import Column, Integer, String, Text, DateTime
from sqlalchemy.sql import func
from app.database import Base

class AIGenerationLog(Base):
    __tablename__ = "ai_generation_logs"

    id = Column(Integer, primary_key=True, index=True)
    student_id = Column(Integer, nullable=True)
    feature_type = Column(String(100), nullable=False)
    prompt = Column(Text, nullable=False)
    response = Column(Text, nullable=False)
    created_at = Column(DateTime(timezone=True), server_default=func.now())
```

## Djangoとの連携方法

### 案1：DjangoからHTTPでFastAPIを呼ぶ

Django側で以下のように呼び出す。

```python
import requests

def call_ai_lesson_feedback(payload):
    response = requests.post(
        "http://ai_service:8001/ai/lesson-feedback",
        json=payload,
        timeout=30
    )
    response.raise_for_status()
    return response.json()
```

この方式が一番わかりやすく、ポートフォリオ向きです。
